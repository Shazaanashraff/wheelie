Wheelie: from fifteen apps to one wheel

A 60-second, fully animated trailer. A desktop drowns in single-purpose apps until it overheats. Wheelie rolls in, puts out the fire, swallows every app, and becomes the wheel. Then we show what it does and how to get it. No title cards: every word appears inside the scene.

The one rule: no slides

Every word is a thing in the world: a notification, a chat bubble, a scanner tag, a memory graph label, a keycap, a tire track. No text-left / picture-right layouts, no static title cards, and the camera never holds still for more than about a second and a half.

Character and wheel

Placeholder look until you send real brand assets.

Wheelie, the character

A tire-bodied mascot with its face in the hub. It rolls everywhere instead of walking, and the tire spins faster when it is working. Four poses needed: neutral, alarmed, hero (extinguisher), nerd (glasses). The same face sits in the hub of the wheel UI, so character and product read as one thing.

The wheel, eight slots

Opens around the cursor on Alt + Space. Each slot is one tool; picking one slides it out into the full tool. A slot can also launch an installed app. A ninth "+" slot appears only in shot 15, for custom tools.

How it gets made

Production plan

Built in code so every frame is editable and the UI stays crisp.

Approach

  • Remotion (React-based video) renders every shot from code. Real UI, real text, exact timing. A change is an edit and a re-render, not a re-animation.
  • Character is a vector rig animated in code, so Wheelie looks identical in all 18 shots.
  • AI generation for character concept options and the music bed / SFX. Google Flow isn't connected to this session; Higgsfield and Canva are, so I'd use Higgsfield. I'd keep AI video out of the UI shots, because it warps text and window chrome.
  • Output 1920×1080 MP4 at 60 fps. A 4K master and a 9:16 vertical cut for socials are optional extras.

Steps after approval

  1. Lock the character, palette and the eight tools.
  2. Animatic with real timing and temp music. You review pacing.
  3. Full animation, act by act. You review each act.
  4. Sound pass: music, SFX hits on every beat called out above.
  5. Final render and hand-off, plus the trailer cut that opens the long video.
